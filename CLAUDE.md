# Tessera

An unofficial Sankaku client for Android and macOS, on Kotlin Multiplatform and Compose Multiplatform.

- `README.md`: what it is, installing, privacy.
- `CONTRIBUTING.md`: building, the module boundaries, the API rules, versions, checks and releases.
- `GLOSSARY.md`: the domain's words.

Run the narrowest Gradle tasks that cover a change through `scripts/gradlew`; CI runs the full build.
